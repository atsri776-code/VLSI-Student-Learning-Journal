# RTL Simulation

## Description

RTL simulation using Icarus Verilog to compile Verilog designs,
execute testbenches, generate simulation output, and observe
functional behavior.

## Topics Covered

- Verilog compilation
- RTL simulation
- Testbench execution
- VCD waveform generation
- Simulation debugging
- Signal observation

## Learning Outcome

Developed practical experience in compiling and simulating RTL
designs and generating waveform data for functional analysis.
