# Day 01 — MUX RTL Design and Simulation

## Objective

Design and simulate a 2:1 multiplexer using Verilog RTL.

## Concepts Learned

- 2:1 Multiplexer
- Verilog RTL
- Inputs and outputs
- Select signal
- Conditional operator
- Testbench
- Simulation
- GTKWave waveform analysis

## MUX Logic

- `sel = 0` → `y = i0`
- `sel = 1` → `y = i1`

## Tools Used

- Icarus Verilog
- GTKWave

## Learning Outcome

Understood the basic RTL design and simulation flow:

**Verilog RTL → Testbench → Simulation → Waveform**
