# Day 03 — Flip-Flops and Sequential Logic

## Objective

To understand the basic concepts of sequential logic and flip-flop based RTL design.

## Concepts Learned

- Sequential logic
- Clock signal
- Reset signal
- D flip-flop
- Register
- Non-blocking assignment
- Clocked always block
- Timing behavior
- RTL simulation

## Basic RTL Flow

Clock + Reset
     ↓
Sequential RTL
     ↓
Simulation
     ↓
Waveform Analysis
     ↓
Synthesis

## What I Learned

I learned how sequential circuits store information using flip-flops and registers. I also understood how clock and reset signals control sequential RTL behavior.

## Tools Used

- Verilog
- Icarus Verilog
- GTKWave
- Yosys

## Learning Outcome

I gained a basic understanding of designing, simulating, and analyzing sequential logic using Verilog RTL.
