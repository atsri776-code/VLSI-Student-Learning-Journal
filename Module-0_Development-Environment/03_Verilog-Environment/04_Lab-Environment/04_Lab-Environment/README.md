# Lab Environment

## Description

End-to-end laboratory workflow used for RTL development, Verilog compilation, simulation, waveform generation, and design analysis.

## Workflow

Verilog RTL
     ↓
Icarus Verilog
     ↓
Simulation
     ↓
VCD Generation
     ↓
GTKWave
     ↓
Waveform Analysis

## Tools Used

- Linux / Ubuntu
- Verilog HDL
- Icarus Verilog
- GTKWave
- Yosys

## Learning Outcome

Gained practical familiarity with the RTL laboratory workflow and the tools required to develop, simulate, and analyze digital designs.
