# Verilog Environment

## Description

Basic Verilog HDL development environment used for creating RTL designs, developing testbenches, compiling source files, and performing functional simulation.

## Topics Covered

- Verilog HDL source files
- RTL module structure
- Design and testbench organization
- Verilog compilation
- Simulation workflow
- Testbench execution

## Learning Outcome

Developed familiarity with the Verilog development workflow required for RTL design and functional verification.
