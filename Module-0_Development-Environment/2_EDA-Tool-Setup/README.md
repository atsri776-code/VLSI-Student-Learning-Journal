# EDA Tool Setup

## Description

Setup and basic usage of EDA tools used for RTL simulation, waveform analysis, and design visualization.

## Tools Covered

- Icarus Verilog
- GTKWave
- DOT / Netlist Viewer

## Files

- `loading a file in iverilog.PNG`
- `gtkwave for good mux.PNG`
- `dot viewer.PNG`

## Learning Outcome

Gained practical familiarity with compiling Verilog designs, viewing simulation waveforms, and visualizing synthesized design structures.
