# Verilog RTL Design

## Description

Verilog RTL implementations covering combinational and sequential
digital logic, multiplexers, arithmetic circuits, counters, and
synthesis-friendly coding practices.

## Topics Covered

- Verilog HDL
- RTL modeling
- Combinational logic
- Sequential logic
- Multiplexer design
- Arithmetic circuits
- Counter design
- Conditional constructs
- Synthesizable RTL coding

## Learning Outcome

Developed practical experience in writing Verilog RTL modules and
understanding how HDL descriptions represent digital hardware.
