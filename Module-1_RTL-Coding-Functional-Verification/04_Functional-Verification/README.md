# Functional Verification

## Description

Functional verification of RTL designs by comparing expected and
observed behavior through simulation results and waveform analysis.

## Topics Covered

- Functional correctness
- Simulation-based verification
- Signal monitoring
- Waveform inspection
- Expected-versus-observed behavior
- RTL debugging

## Learning Outcome

Developed the ability to analyze simulation results and waveforms
to identify functional issues and verify RTL design behavior.
