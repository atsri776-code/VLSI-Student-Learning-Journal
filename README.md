# VLSI Student Learning Journal

A student-level learning portfolio documenting my journey through **Verilog RTL Design, Simulation, Synthesis, and Netlist Analysis** using open-source VLSI tools.

## About This Repository

This repository contains my RTL design exercises, simulation results, synthesis observations, netlists, and learning notes from VLSI design and synthesis practice.

The main tools and concepts covered are:

- Verilog RTL Design
- Icarus Verilog
- GTKWave
- Yosys
- Liberty files
- SKY130 standard-cell library
- RTL-to-netlist synthesis
- Hierarchical design
- Netlist analysis
- Flip-flop coding
- RTL optimization
